# blog-watcher
## MVP
- C#を職場で使うことになったのでアウトプットをしたい

- mercari社のDBの記事など、特定企業の特定のワードを含む記事が新たに公開されていないか定期的にチェックして、自分のgmailに投稿するツールを作成したい
  - 特定の会社ブログに依存した作りにしない。
  - 最初の対象ブログはRSSフィードが存在する以下のブログ
    - https://engineering.mercari.com/blog/ , TiDBという文字列が含まれている記事を対象とする
    - https://read-uncommitted.com/ , TiDB WEEKLYという文字列が含まれている記事を対象とする

- チェック頻度は1日1回 朝8時に行う

- 新規記事があった場合、記事タイトルをGmailで送信する

## 次のバージョンでやりたいこと
- 新規記事があった場合、記事内容をOpenRouterなどを経由したLLMで要約して、メールに記載する

- 対象のLLMがクレジット不足などで使えなかった場合,別モデルでフォールバックして処理する

- OSSのリリースがあった場合、それもメールに記載する。できれば要約する。
